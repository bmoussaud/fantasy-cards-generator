# Historical AI-development decisions

These are preserved project decision records from before the HVE Core migration:

- [Recorded decisions, August-September 2026](development-decisions-2026.md)
- [Earlier decisions and superseded proposals](development-decisions-archive-2026.md)

They are **historical evidence, not active agent instructions**. Statements such
as "active", pending approvals, previous deployment commands, team routing,
review lockouts, model fallbacks, and runtime mocks describe their original
context; do not treat them as present-day policy or permission to resume work.
Old paths, author names, issue labels, and branch names remain as provenance.
The original team logs/histories remain available in Git history.

Current guidance is in [Copilot instructions](../../.github/copilot-instructions.md),
[HVE setup](../hve-core.md), the [change workflow](../issue-to-copilot-workflow.md),
and maintained application/operations documentation. Current source and those
documents take precedence over superseded decisions.
